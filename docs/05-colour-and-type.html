Cream & Gold

Colour and type, lifted from the the city draft app's light theme. This page is itself built with the palette — what you're looking at is the scheme. Six steps, then a copy-paste block at the end.

The whole idea in one sentence: a warm cream page, off-white cards floating on it, near-black-brown text, and one accent colour — a deep antique gold — used sparingly for labels and numbers. No pure white, no pure black, no grey. Everything is warm-tinted.

01 The font

Whatever the device already has. No web font, no download, no loading flash.

font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
             Helvetica, Arial, sans-serif;

On an iPhone that renders as San Francisco, on Android as Roboto, on Windows as Segoe. It looks native everywhere because it is native. The personality comes from the weights, not the typeface — this scheme leans hard on very heavy weights next to light grey captions, and that contrast is most of the look.

Three rules that matter more than the sizes:

Headings are 800–900, never 600 or 700. Semibold reads as timid in this scheme. Go heavy or go normal.

Small uppercase labels always get letter-spacing — 1.2px at 12px, 2px at 11px. Uppercase without tracking looks cramped and cheap; with it, it reads as deliberate.

Any number that updates gets font-variant-numeric: tabular-nums so digits keep the same width and nothing jitters when the value changes.

02 The surfaces

Four warm creams, light to dark. The whole layout is built by stacking these — no shadows needed to create hierarchy, just the steps between them.

--bg#f6f1e2
The page. Warm cream, never white.
--card#fffdf4
Card top. Lighter than the page, so cards float forward.
--card-2#f5eeda
Card bottom. Cards are a gradient from --card to this — a very subtle top-lit effect.
--bg-2#ede5cf
Tiles, wells, stat boxes, anything recessed inside a card.
--line#dcd2b6
Every border and divider in the app. One line colour, no exceptions.

The card is the workhorse — copy this exactly:

.card {
  background: linear-gradient(180deg, var(--card), var(--card-2));
  border: 1px solid var(--line);
  border-radius: 16px;
  padding: 16px;
  box-shadow: 0 6px 24px rgba(90, 74, 30, 0.10);
}

Note the shadow is warm brown at 10%, not black. A black shadow on cream turns grey and instantly looks like a different design. Radii step down as things nest: 16px cards, 12–14px tiles inside them, 999px pills.

03 The text

--text#251e0d
Headlines and anything that must be read first. Very dark warm brown — not black.
--text-2#4a4331
Body copy and paragraphs.
--muted#6b6149
Captions, timestamps, secondary numbers, anything deliberately quiet.

Three levels is the whole system. If something needs to be quieter than --muted, it should probably be smaller or deleted, not greyer.

04 The accent

One accent colour, in three depths. This is the signature of the scheme, and it's the thing most likely to go wrong: the gold is dark. In the dark theme this app's gold is a bright #f5c518; on cream that same yellow is nearly invisible, so the light theme swaps in a deep antique gold that happens to read as brown-gold. Same role, different value.

--gold#7f5e05
Section labels, card headers, small accents. The default.
--gold-2#7c5c07
Big numbers and hero values. Practically identical to --gold on purpose — it's the dark-theme counterpart that differs.
--gold-3#5f4605
Deepest gold. Inline code, rare emphasis.

Use it sparingly. Gold appears on uppercase section labels, on hero numbers, and on primary buttons. That's it. It is not a body-text colour and it is not a link colour. The restraint is what makes it read as expensive rather than as a highlighter.

The one place the bright gold survives in light mode is a filled button, where it's a background rather than text:

.btn-primary {
  background: linear-gradient(180deg, #ffd84a, #b8860b);
  color: #251e0d;
  border: none; border-radius: 12px;
  padding: 12px 18px; font-weight: 900;
  background-origin: border-box;  /* see the gotcha in §6 */
}

05 Status colours

Two, plus a small set of optional extras. Both are darkened for cream — the dark theme's #ff4d4d and #6dd57a are far too light here.

--green#1a6e34
Good, done, confirmed, available.
--red#c22f22
Bad, errors, cancelled, unavailable.
blue#2f5faf
Optional. Info, cool, water.
rust#a3441c
Optional. Warning, heat, attention.

Status colours go on text and borders, not fills. A pill gets the coloured text on a --bg-2 background with a border of the same hue at ~45% alpha. Solid colour-filled badges break the calm of the scheme immediately.

neutral  ✓ confirmed  cancelled 

.pill {
  font-size: 11px; font-weight: 800; letter-spacing: .4px;
  padding: 3px 9px; border-radius: 999px;
  background: var(--bg-2);
  border: 1px solid var(--line);
  color: var(--muted);
}
.pill-go { color: #1a6e34; border-color: rgba(26,110,52,0.45); }
.pill-no { color: #c22f22; border-color: rgba(194,47,34,0.45); }

07 Gotchas

This is not the dark theme inverted. Every colour was re-picked for cream. If you take the dark values and flip the lightness you get muddy olive text and an invisible gold. Treat them as two hand-made palettes that share names.

Shadows are brown, never black. rgba(90,74,30,0.10). A black shadow greys out the warmth.

Emoji need help on cream. Yellow and white glyphs — suns, clouds — nearly disappear. Re-ink their edges:

filter: drop-shadow(0 1px 1.5px rgba(37, 30, 13, 0.5));

Gradient buttons need background-origin: border-box. Without it a gradient sized to the padding box gets painted across the border box and repeats a sliver at the top edge — it looks like a faint darker stripe and it's maddening to diagnose.

09 Copy-paste

Everything above, as one block. Drop it at the top of the stylesheet and reference the variables from there on.

:root {
  /* surfaces — warm cream, light to dark */
  --bg:      #f6f1e2;   /* page */
  --card:    #fffdf4;   /* card top */
  --card-2:  #f5eeda;   /* card bottom (gradient) */
  --bg-2:    #ede5cf;   /* tiles / wells inside cards */
  --line:    #dcd2b6;   /* every border */

  /* text — three levels, warm brown, never grey */
  --text:    #251e0d;   /* headlines */
  --text-2:  #4a4331;   /* body */
  --muted:   #6b6149;   /* captions */

  /* accent — deep antique gold, used sparingly */
  --gold:    #7f5e05;   /* labels, headers */
  --gold-2:  #7c5c07;   /* hero numbers */
  --gold-3:  #5f4605;   /* deepest */

  /* status */
  --green:   #1a6e34;
  --red:     #c22f22;
  --blue:    #2f5faf;   /* optional */
  --rust:    #a3441c;   /* optional */

  /* button fill — the one place bright gold survives */
  --btn-hi:  #ffd84a;
  --btn-lo:  #b8860b;

  /* type */
  --font: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
          Helvetica, Arial, sans-serif;

  /* depth — warm shadow, never black */
  --shadow: 0 6px 24px rgba(90, 74, 30, 0.10);
}
